# Code of Conduct

We want LUK Image Workspace to be a useful, calm, and technically rigorous project.

Participants are expected to:

- be respectful and assume good faith;
- focus critique on behavior, evidence, and code rather than people;
- protect other people’s privacy and creative work;
- disclose security concerns privately;
- make space for contributors with different backgrounds and levels of experience.

Harassment, discrimination, doxxing, credential sharing, malicious reports, and intentional exposure of private assets are not acceptable. Maintainers may remove content or restrict participation when necessary to keep the project safe.
