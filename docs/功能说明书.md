# AI 图像工作台：功能说明书

## 使用前先知道

- 素材先在本地选择，点击“提交生成”后才会上传。
- 单个生成任务最多组合 4 张参考图。
- 生成前请核对线路、比例、质量、分辨率、张数和预计积分。
- 批量任务中的每个子任务都可以独立查看、下载或重试。

## 一键详情 4.0

适合：为一个商品快速制作视觉统一、卖点完整的详情页图片。

1. 上传 1 张商品主图；需要指定视觉方向时，可再上传最多 3 张风格参考图。
2. 填写商品名称、核心卖点，以及不希望画面出现的内容。
3. 点击“生成 8 组场景方案”。此时只生成策划方案，不立即批量出图。
4. 逐项修改方案文字；不需要的方案可以关闭。
5. 核对启用数量、生成参数和预计积分，再提交生成。

建议：主图尽量主体清楚、背景干净；卖点用具体事实，不要只写“高级、好看”。

## 批量复刻

适合：把多张参考图的构图、光线和视觉风格迁移到自己的商品上。

1. 一次上传最多 20 张复刻参考图，每张参考图对应一个独立任务。
2. 如需替换为自己的商品，再上传最多 3 张商品图；不上传则以复刻画面风格为主。
3. 填写整批共用要求，例如“保留构图，替换商品，删除原图文字”。
4. 核对生成参数后提交，完成后逐张检查结果。

建议：同一批参考图尽量属于同一视觉方向；差异过大时拆成多批，结果更稳定。

## 批量 SKU

适合：使用同一视觉模板，批量制作不同颜色、容量、规格或款式的 SKU 图片。

1. 上传最多 20 张 SKU 商品图，并按最终出图顺序排列。
2. 上传 1 张统一模板图，系统会沿用它的版式、背景和光线。
3. 在“SKU 属性”中逐行填写规格；第 1 行对应第 1 张商品图，以此类推。
4. 填写整批共用要求，核对参数后提交生成。

建议：商品图拍摄角度尽量一致；属性行数最好与商品图数量一致，避免错配。

## 局部裁切

适合：只修改场景图中的一块区域（如替换商品、手部佩戴、局部重绘），并尽量保护框外人物、文字、Logo 与构图。

1. 上传场景图，点击「编辑场景图」。
2. 用画笔涂出灰色选区（可用橡皮擦修正），再设置正方形裁切框；无裁切框时不能生成。
3. 可选上传最多 3 张产品参考图（作为图2/图3/图4）。
4. 确认提示词（默认会说明灰色选区替换与消除）、线路与分辨率，点击「开始生成」。
5. 生成完成后，系统会把结果羽化回贴到原图对应位置，并保留生成原片。

建议：灰色选区完整包住替换目标并留一点融合边；提示词写清“替换什么、保留什么”。快捷键：B 画笔、E 橡皮、C 裁切框、⌘Z 撤销。

## 一键带货转台

适合：用一张商品主图生成 8 个环绕视角，在 App 内旋转预览，并导出循环短视频（WebM）。

1. 上传 1 张商品主图（建议白底、单主体）；可选再加最多 2 张辅助参考图。
2. 核对线路、比例、质量、分辨率与预计积分（约为单次图生图价 × 8）。
3. 点击生成；系统会按 0°/45°/…/315° 提交 8 个独立图生图任务。
4. 视角完成后可在中间预览区自动旋转或点选单角度；需要时可导出 WebM 到工作目录。

说明：这是「多视角假转台」，只消耗现有生图积分，不调用额外 3D 或 LLM 服务。导出格式为 WebM；若平台要求 MP4，可先用系统工具转换。

## 常见问题

- 结果与参考图不一致：减少同一任务中的参考图数量，并把“必须保留”的内容写具体。
- 批量结果差异较大：把视觉风格不同的素材拆成多批。
- 局部修改影响框外：缩小裁切框，并在提示词中再次强调框外保护。
- 未设置裁切框：请先在「编辑场景图」中添加裁切框后再提交。
- 转台视角商品不一致：主图尽量白底清晰；可在补充要求里强调“包装与标签不得改动”。
- 分辨率越高，通常处理时间和积分也越高；以提交前界面显示为准。
