# LUK Image Workspace 功能说明书

## 使用前先知道

- 这是一个无登录、BYOK（Bring Your Own Key）的 macOS 桌面工具。
- 在 Settings 中填写 `API Base URL`、`API Key` 和 `Image2 Model`。根地址和带 `/v1` 的地址都会自动规范化。
- 首次保存 API Key 前，应用会检查 macOS 的安全凭证存储；不支持安全存储时不会明文保存。
- API Key 只会随 `Authorization: Bearer` 请求发送到你填写的兼容服务。应用不提供账号、积分、充值、远程历史或隐式上传接口。
- 生成结果完成后立即落盘到本机工作目录，并记录本地路径和 SHA-256。历史只读取本机文件，不保存带签名参数的远程 URL。
- Photopea 是用户主动打开时才使用的第三方远程编辑服务；打开文件前请确认你接受文件会发送给 Photopea。

## Quick Generate / 快速生成

1. 在 Settings 配置兼容 Images API。
2. 选择 Text to Image 或 Image to Image。
3. 输入提示词，可选加入最多 4 张参考图。
4. 选择比例、质量、分辨率和数量后提交。
5. 应用调用 `/v1/images/generations` 或 `/v1/images/edits`，并把结果立即保存到本机。

## 一键详情

适合：为一个商品快速制作视觉统一、卖点完整的详情页图片。

1. 上传 1 张商品主图；需要指定视觉方向时，可再上传最多 3 张风格参考图。
2. 填写商品名称、核心卖点，以及不希望画面出现的内容。
3. 点击“生成 8 组场景方案”。此时只生成策划方案，不立即批量出图。
4. 逐项修改方案文字；不需要的方案可以关闭。
5. 核对启用数量和生成参数后提交。

## 批量复刻

适合：把多张参考图的构图、光线和视觉风格迁移到自己的商品上。

1. 一次上传最多 20 张复刻参考图，每张参考图对应一个独立本地任务。
2. 如需替换为自己的商品，再上传最多 3 张商品图；不上传则以复刻画面风格为主。
3. 填写整批共用要求，例如“保留构图，替换商品，删除原图文字”。
4. 提交后逐张检查本地产物；失败任务可以重新提交。

## 批量 SKU

适合：使用同一视觉模板，批量制作不同颜色、容量、规格或款式的 SKU 图片。

1. 上传最多 20 张 SKU 商品图，并按最终出图顺序排列。
2. 上传 1 张统一模板图，系统会沿用它的版式、背景和光线。
3. 在“SKU 属性”中逐行填写规格；第 1 行对应第 1 张商品图，以此类推。
4. 填写整批共用要求，核对参数后提交。

## 局部裁切 / Local Crop

适合：只修改场景图中的一块区域，并尽量保护框外人物、文字、Logo 与构图。

1. 上传场景图，点击「编辑场景图」。
2. 用画笔涂出灰色选区，可用橡皮擦修正；再设置正方形裁切框。
3. 可选上传最多 3 张产品参考图。
4. 确认提示词、线路与分辨率，点击「开始生成」。
5. 生成完成后，应用把结果羽化回贴到原图对应位置，并保留生成原片与本地合成图。

建议：灰色选区完整包住替换目标并留一点融合边；提示词写清“替换什么、保留什么”。快捷键：B 画笔、E 橡皮、C 裁切框、⌘Z 撤销。

## Image → PSD

选择本机商品图即可使用本地分层工具，不需要 Provider 配置。PSD 结果保存在本机，可继续使用 Photoshop 或用户主动打开 Photopea 编辑。

## 一键带货转台 / 8-angle Turntable

1. 上传 1 张商品主图，可选再加最多 2 张辅助参考图。
2. 核对比例、质量和分辨率后提交。
3. 应用按 0°/45°/…/315° 创建 8 个独立本地任务，每个任务直接调用兼容 Images API。
4. 视角完成后可在应用内旋转预览，或导出 WebM 到本机工作目录。

说明：这是基于多视角图片的预览工作流，不是 3D 建模；服务商的费用、速率和限制由服务商自行决定。

## 常见问题

- 结果与参考图不一致：减少同一任务中的参考图数量，并把“必须保留”的内容写具体。
- 批量结果差异较大：把视觉风格不同的素材拆成多批，检查服务商的编辑能力。
- 局部修改影响框外：缩小裁切框，并在提示词中再次强调框外保护。
- 服务返回“不支持 edits”：当前 Provider 没有实现 `/v1/images/edits`；应用不会回退到登录或私有接口。
- URL 结果下载失败：先检查服务商返回的临时 URL 是否仍有效，并重新提交任务；已经落盘的本地产物不受远程 URL 失效影响。
- 高分辨率处理更慢或被拒绝：这是服务商的模型能力和限制，应用会展示脱敏后的 HTTP 错误。
